# 连接设备 (connect)

建立与虚拟设备的网络连接。

## 参数

- `ip` (必需): 设备IP地址，例如 "127.0.0.1"
- `port` (可选): 设备端口号，默认 8000，范围 1-65535

## 示例

用户说："连接到 127.0.0.1"
解析为：
```json
{
  "action": "connect",
  "params": {"ip": "127.0.0.1"}
}
```

用户说："连接设备，IP是127.0.0.1，端口8080"
解析为：
```json
{
  "action": "connect",
  "params": {"ip": "127.0.0.1", "port": 8080}
}
```

## 注意事项

- 连接前无需断开已有连接，系统会自动处理
- 连接成功后会返回设备ID用于后续操作
- 典型连接延迟约 500ms
